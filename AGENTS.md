# Git branches

Do not name a branch `cursor`, and do not put `cursor` in a branch name.
Name the branch after the change.

# Authorship — no LLM / AI attribution

Do **not** attribute commits, pull requests, tags, releases, issues, comments, or files to Cursor, Claude, Grok, ChatGPT, Copilot, Codex, Gemini, or any other LLM, AI assistant, or AI coding tool.

Forbidden everywhere in git and GitHub:

- `Co-authored-by` trailers naming an AI/LLM tool or agent (including `cursoragent@cursor.com`)
- `Made with`, `Generated by`, `Assisted by`, or similar credits for those tools
- Author / committer identity set to an AI tool name or email

Commits and pull requests are authored only by the human maintainer.
Never add AI co-author trailers when committing, amending, squashing, or opening PRs.
